# Pitch Deck & Demo Materials

## Files

- `pitch_deck.pptx` — Demo Day presentation slide deck
- `video_demo.mp4` — Product demo video (maximum 5 minutes)

## Pitch Deck Structure (10 Slides)

1. **Title** — Project name, team members, team code
2. **Problem** — Core user pain points and quantifiable impact
3. **Solution** — AI Agent capabilities and unique value proposition
4. **Demo** — Product screenshots / interactive walkthrough
5. **Architecture** — Decoupled 3-tier system architecture diagram
6. **Tech Stack** — Technologies and frameworks leveraged
7. **Traction** — Evaluation metrics, user feedback, performance
8. **Market** — Target user personas and market opportunity
9. **Team** — Roles, responsibilities, and contributions
10. **Ask** — Next development milestones and resource needs

## Video Demo Checklist

- [ ] Problem introduction (< 30 seconds)
- [ ] Live demonstration of core AI agent workflow (2-3 minutes)
- [ ] Explanation of system architecture and intelligence layer (1 minute)
- [ ] Impact summary and conclusion (< 30 seconds)
