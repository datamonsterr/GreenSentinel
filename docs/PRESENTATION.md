# Demo Day Pitch Deck & Video Guide

## Presentation Structure (10 Slides)

1. **Title**: Team P-063, GreenSentinel, team members, VinUni AI20K.
2. **Problem Statement**: Concrete user pain point, market data, inefficiencies.
3. **Solution**: AI Agent system overview and unique value proposition.
4. **Live Product Demo**: Video recording or live interaction walkthrough.
5. **System Architecture**: 3-tier architecture diagram, LangGraph orchestration, state graph.
6. **Technical Innovations**: Tool integration, Mnemoverse online memory, custom skills.
7. **Traction / Evaluation**: Benchmark results, latency metrics, user feedback.
8. **Market Opportunity**: Addressable market, target personas.
9. **Team**: Member roles and contributions.
10. **Roadmap & Call to Action**: Next engineering phases and resource requirements.

## Video Demo Guidelines

- **Duration**: Maximum 5 minutes.
- **Pacing**: 30s Problem Introduction -> 2.5m Core Feature Demo -> 1m Technical Architecture -> 30s Impact Summary.
