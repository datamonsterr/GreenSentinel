# Implementation Design Notes

This directory contains dated implementation designs, source analysis, interface decisions, and reproducible test recipes. GitHub issues remain authoritative for acceptance criteria, task checklists, dependencies, ownership, and delivery status. Link the issue instead of copying its backlog here.

Name designs `YYYY-MM-DD-<feature-name>.md`. Record the inspected commit, distinguish existing behavior from proposed changes, link repository files relatively, and distinguish fixture, isolated-database, and hosted evidence.
