## 7. Known-gap quantification

1. **Gridlock SSD false positives: 0/704 (rate 0.0000).** Honest gridlock trips never reach the 180 s stationary threshold, so the heuristic is immune by construction (it never reads DAVI). No fix applied, per spec.
2. **Clock-jitter run: external figure, no rebuild.** A `--noise stress` rebuild of an N=500 subset was skipped as too slow. Per `docs/data/TELEMETRY_DISTRIBUTION.md` finding 3 (400-trip stress variant): full-stress DIC detection **50%**; without clock jitter **66%**; without jitter and stall accuracy ≤ 15 m **73%**.
3. **Keyword brittleness (split by keyword presence in `driver_objection` text; trap flags not persisted in bundles):**
   - ERR-01 (keywords `vô cớ`/`từ chối`/`unjustified`): keyword subset recall **0.9456** (n=147) vs paraphrase recall **0.9632** (n=353). Gap ≈ 0 — because the heuristic keys on the `cancellation_reason` **enum** (`driver_cancelled_unjustified` always contains `unjustified`), ignoring objection phrasing entirely. The brittleness is latent: any paraphrased enum value would drop recall to 0.
   - ERR-04 (keywords `ảo`/`ghost`): keyword recall **0.0000** (n=74) vs paraphrase recall **0.0000** (n=226). Heuristic checks `cancellation_reason` for `ảo`/`ghost`, but ghost trips complete with reason None (and the ghost branch sits below the cancelled branch), and `ghost_no_pickup` is never read. ERR-04 is structurally unemittable — measured, not fixed, per spec. Same mechanism zeroes ERR-03: no `wrong_direction` derivable from `measured_features`, and `route_deviation` matches neither the keyword nor the maneuver condition.
