# P-063 Ride-Hailing Fraud & Violation Benchmark

A synthetic, reproducible benchmark for detecting **fraud and violations in a
single ride-hailing trip**. One row = one trip. Built by Team P-063 (VinUni AI20K
Build Phase). **Repo:** https://github.com/AI20K-Build-Phase-Cohort-4/P-063

## Why

No suitable publicly labelled ride-hailing fraud corpus was identified in this research. PaySim's
≈0.13% rate is a financial-domain proxy and is not measured real-trip fraud prevalence. We generate a deterministic corpus with
an **enriched** class mix so each violation type has enough examples to score a
detector. This mix is a benchmarking choice, not real-world prevalence.

### Class Breakdown (releases_v2.1)

| Category | Description | Count | Share |
|---|---|---:|---:|
| `no_violation` | Policy-compliant, normal trip | 28,000 | 70.0% |
| `ERR-02` | Deliberate stall / waiting out passenger | 3,200 | 8.0% |
| `insufficient_evidence` | Severe telemetry dropout (guardrail-only) | 2,400 | 6.0% |
| `ERR-01` | Unjustified driver cancellation | 2,000 | 5.0% |
| `ERR-03` | Intentional route deviation / wrong direction | 2,000 | 5.0% |
| `ERR-04` | Ghost trip / fake completion | 1,200 | 3.0% |
| `ERR-05` | GPS spoofing / mock location | 1,200 | 3.0% |
| **Total** | | **40,000** | **100.0%** |

### Driver Split (Zero Leakage)

- **Train:** 28,000 trips (1,400 drivers)
- **Validation:** 6,000 trips (300 drivers)
- **Test:** 6,000 trips (300 drivers)
- **Distinct Drivers:** 2,000 (disjoint partitions; driver leakage = 0)

## Benchmark Highlights (releases_v2.1 Test Split, 6,000 Trips, `--enum-blind`)

| Architecture / Model | Test Sample | Macro-F1 [95% CI] | Accuracy | `no_violation` FPR | ECE |
|---|---:|---|---|---|---|
| **R3D Stacker** (R3C GBM + R3F CNN) | 6,000 | **0.8680 [0.861, 0.875]** | **0.9507** | **0.027** | **0.056** |
| R3C Clean LightGBM (37 features) | 6,000 | 0.8618 [0.856, 0.869] | 0.9398 | 0.080 | 0.053 |
| R3F Trajectory 1D-CNN (GPS seq) | 6,000 | 0.8205 [0.813, 0.828] | 0.9610 | 0.0005* | 0.170 |
| Inception Mercury Free (`evidence_classref`) | 300 | 0.5155 [0.455, 0.575] | 0.5833 | 0.357 | 0.391 |

*\*R3F test FPR is 0.000481 (~0.05%, 2 false positives / 4,159 normal test trips), rounded to 0.000 in integer summaries; not zero.*
*Note: Models learn 6 violation/non-violation categories. The 7th outcome, `insufficient_evidence`, is produced exclusively by data validity guardrail short-circuits on telemetry dropouts.*

## How to Fetch

### Using Hugging Face CLI (`hf`):

```bash
# Fetch current synthetic research corpus (releases_v2.1) pinned to immutable revision:
hf download datamonsterr/p-063-synthesized-trips \
  --repo-type dataset \
  --include "releases_v2.1/*" \
  --revision abb8cc8b2464aacdcbec0aab039ef4e066f71f8e \
  --local-dir data/benchmark-10k

# Fetch historical releases_v2:
hf download datamonsterr/p-063-synthesized-trips \
  --repo-type dataset \
  --include "releases_v2/*" \
  --revision cc8023b7022fdd5392a5655135712cc748967814 \
  --local-dir data/benchmark-10k
```

### Using Repository Fetch Helper:

```bash
# Fetch releases_v1:
python scripts/benchmark/fetch_dataset.py --profile releases_v1 --out data/benchmark-10k

# Fetch Vietnam 1k release:
python scripts/benchmark/fetch_dataset.py --profile synthesized_vietnam_trip --out data/benchmark-10k
```

The fetcher and CLI verify downloaded files against the recorded SHA-256 checksums.
